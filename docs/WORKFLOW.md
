# MEASURE VERIFY - System Workflow

## Overview

MEASURE VERIFY digitizes the verification lifecycle of weighing and measuring instruments.

## Workflow

The complete workflow is:

Register Instrument
→ Apply for Verification
→ Schedule Inspection
→ Digital Inspection
→ Verify
→ Risk Analysis
→ Digital Certificate
→ QR Verification
→ Validity Tracking
→ Re-verification

## 1. Instrument Registration

The user registers an instrument by entering:

- Instrument number
- Instrument type
- Manufacturer
- Model
- Capacity
- Owner name
- Location

## 2. Verification Application

The user submits a verification or re-verification application for the registered instrument.

## 3. Inspection Scheduling

The LMO can view pending applications and schedule an inspection by assigning an inspector and scheduled date.

## 4. Digital Inspection

The inspector records:

- Inspection observations
- Verification result
- Failure count
- Remarks

## 5. Verification Result

The application is marked as Verified or Rejected based on the inspection result.

## 6. Risk Analysis

The system analyzes verification history using rule/statistical risk analysis and assigns a LOW, MEDIUM or HIGH risk level.

## 7. Digital Certificate

For a successful verification, the system generates a digital certificate containing certificate and instrument information.

## 8. QR Verification

A QR code is generated for the certificate and can be used to access certificate verification information.

## 9. Certificate Integrity

SHA-256 hashing is used to check whether the stored certificate record remains intact.

## 10. Audit Trail

Important actions such as login, inspection scheduling, inspection completion and certificate generation are recorded in the audit log.
